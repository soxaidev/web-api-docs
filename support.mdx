## Request production access

The production-access request form is not yet available. For information about requesting access, contact [info@soxai.co.jp](mailto:info@soxai.co.jp). Do not include an API key, password, or other secret in your message.

Read the [privacy policy](https://soxai.co.jp/policies/privacy-policy) before submitting personal information.

## Ask a question about using the API

Production-access requests are individual and non-public. For questions about using the API, email [info@soxai.co.jp](mailto:info@soxai.co.jp). This link will move to the public API discussions forum when it is available.
