## Request production access

Production-access applications are handled privately. The dedicated form is being prepared. Until it is available, apply by emailing [info@soxai.co.jp](mailto:info@soxai.co.jp) with the subject `Production access request`. Do not include an API key, password, or other secret in your message.

## Ask a question about using the API

For questions about using the API, email [info@soxai.co.jp](mailto:info@soxai.co.jp). This address receives both usage questions and, for now, production-access applications; use the subject above for the latter. Usage questions will move to the public API discussions forum when it is available.
