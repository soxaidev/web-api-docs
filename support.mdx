## Request production access

Use this private form to request access to the production SOXAI API. Do not include an API key, password, or other secret in the form.

Read the [privacy policy](https://soxai.co.jp/policies/privacy-policy) before submitting personal information. Form responses are processed by Google.

## Ask a question about using the API

Use the production-access form for individual, non-public access requests. For questions about using the API, email [info@soxai.co.jp](mailto:info@soxai.co.jp). This link will move to the public API discussions forum when it is available.
